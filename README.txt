THREAD & FORM — MarkupHive ready-made clothing website demo

OPEN: index.html (or use VS Code Live Server).

EDIT PRODUCTS: js/main.js -> PRODUCTS array near the top. Change name, price, category, sizes, colors, image, description.

EDIT MESSENGER: shop.html -> find YOUR_PAGE_USERNAME and replace in href AND data-page. Important: the checkout modal is repeated in every HTML page, so replace in ALL four pages.

EDIT WHATSAPP: replace YOUR_WHATSAPP_NUMBER in data-number in ALL four HTML pages, using digits with country code (example 639XXXXXXXXX).

EDIT BRAND/CONTENT: HTML files; colors and layout in css/style.css.

IMAGES: demo images are loaded from Unsplash URLs; replace them with your own product photos or local asset paths before selling.

NOTE: This is a static website, not an online payment system or secure owner dashboard. Cart contents are in browser memory and reset on reload. The user must manually copy and send the order through Messenger, or open WhatsApp with the prepared message. No orders are stored on a server.

Demo pricing, descriptions, contact details, brand claims, and sizing are placeholders. Verify and replace them before handing to clients.
